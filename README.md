# Media Overlay

Компактный оверлей с информацией о треке для **Android-магнитол** и других
автомобильных Android-устройств. Когда в любом музыкальном приложении,
публикующем MediaSession (Spotify, YouTube Music, Яндекс Музыка, VLC, Poweramp,
локальные плееры, …), меняется трек, поверх текущего приложения (например,
навигатора) выезжает небольшая «стеклянная» карточка, остаётся на несколько
секунд и уезжает обратно — не перехватывая фокус и не блокируя касания по
приложению под ней.

## Установка

1. Скачайте `MediaOverlay-<версия>.apk` из [последнего релиза](https://github.com/dosoft/mediaoverlay/releases/latest).
2. На устройстве разрешите установку из этого источника и откройте файл.
3. Запустите приложение, выдайте разрешения «Поверх других приложений» и доступ
   к уведомлениям, включите сервис.
4. Включите музыку — карточка появится при смене трека.

Дальше приложение обновляется само: раз в сутки (и по кнопке в настройках) оно
проверяет `latest.json` и по вашему подтверждению скачивает новую версию.

## Что внутри

- шесть оформлений: Linen, Porcelain, Obsidian, Night Drive, Aurora, Blueprint;
- смена темы тапом по плашке, без захода в настройки;
- позиция, ширина, тайминги и анимации появления;
- крупные сенсорные цели и контраст, рассчитанные на дневную и ночную езду;
- без телеметрии: в сеть приложение выходит только для проверки обновлений.
